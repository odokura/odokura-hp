# マネタイズ

## 原則

1. 個人情報を隠すという安全機能そのものは無料で提供する。Hatsu-go の基本記録機能と同じく、
   安全に直結する機能を課金対象にしない。
2. 有料は「効率化」「表現の幅」に置く。
3. サーバーを使わない前提と両立する（レシート検証は端末内）。

## 方式

フリーミアム + ストア課金（react-native-iap 相当）。NeteClay と同様、買い切り中心とし、サブスクは
採用しない。

| 提供物 | 無料 | 有料 |
| --- | --- | --- |
| 撮影・読み込み、顔検出・マスク、Exif 除去、手動マスク編集 | ○ 無制限 | — |
| マスクスタイル（ぼかし・モザイク・単色塗りつぶし） | ○ | — |
| 追加マスクスタイル（スタンプ柄の追加パックなど） | — | ○ |
| 複数枚バッチ処理 | 1 枚ずつなら無制限 | 複数枚一括（行事写真のまとめ処理） |
| 車のナンバープレート検出等 Phase 2 機能 | — | 導入する場合は有料 |

## 購入導線

- 設定内の控えめな導線と、有料機能に触れたときの案内のみに絞る。
- 就寝フローに相当するような「必須の安全操作」の途中には購入導線を出さない（編集・書き出しの
  途中に割り込ませない）。
- 復元（restore purchases）を用意する。サーバーレスのためストアのレシートが唯一の根拠になる。
