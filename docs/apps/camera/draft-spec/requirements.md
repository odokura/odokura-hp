# カメラアプリ 要件メモ

## 機能要件（MVP）

| ID | 要件 | 優先度 |
| --- | --- | --- |
| F-01 | 写真を撮影する、または端末の写真ライブラリから読み込める | 高 |
| F-02 | 撮影・読み込み後、顔検出を自動実行し検出結果を枠で提示する | 高 |
| F-03 | 検出した顔は既定でマスク状態にする（opt-out）。タップでマスクの表示 / 非表示を切り替えられる | 高 |
| F-04 | マスクスタイル（ぼかし / モザイク / 単色塗りつぶし / スタンプ）を選べる | 高 |
| F-05 | 検出漏れに対応するため、手動でマスク領域を追加できる（矩形 / フリーハンド） | 高 |
| F-06 | 追加した手動マスクの位置・大きさを調整・削除できる | 中 |
| F-07 | 書き出し時に Exif メタデータ（位置情報・端末情報・撮影日時など）を除去できる。位置情報は既定オン | 高 |
| F-08 | 書き出しはマスクを画像へ焼き込んだ（flatten）状態で行い、元の顔などを復元できない形にする | 高 |
| F-09 | 書き出し後の画像を写真ライブラリに保存、または OS 共有シートで直接共有できる | 高 |
| F-10 | 元の（マスクなし）画像はアプリ内にのみ一時的に保持し、書き出すまでは写真ライブラリに保存しない | 高 |
| F-11 | 検出信頼度が低い場合（暗い・小さい・横顔など）に、見た目で示す | 低 |

## 機能要件（Phase 2・要技術検証）

| ID | 要件 | 優先度 |
| --- | --- | --- |
| F-12 | 複数枚をまとめて処理するバッチマスキング | 中 |
| F-13 | 車のナンバープレート検出 | 中 |
| F-14 | OCR による文字領域検出（名前・住所などのヒント表示） | 中 |
| F-15 | QR / バーコード検出 | 低 |

## 非機能要件

| ID | 要件 | 優先度 |
| --- | --- | --- |
| NF-01 | 画像・検出結果・メタデータを外部（サーバー）へ送信しない。すべてオンデバイス処理 | 高 |
| NF-02 | ネットワーク接続がなくても主要機能（撮影・検出・マスク・Exif 除去・端末内保存）が動作する | 高 |
| NF-03 | 顔検出からマスク編集までの処理は、一般的な行事写真（1 枚あたり顔十数個程度）でも数秒以内に収まる | 中 |
| NF-04 | 誤って元画像を上書き保存しない。書き出しは常に新規ファイルとして保存する | 高 |
| NF-05 | マスク編集中にアプリがクラッシュ・中断しても、元画像は保持され再編集できる | 中 |
| NF-06 | 対応 OS: iOS / Android の両対応 | 中 |

## 権限

- カメラ、写真ライブラリの読み書きのみ要求する。
- 位置情報の許可は要求しない（Exif の位置情報は除去する側であり、取得はしない）。
- マイク・連絡先などは使用しない。
- 課金（ストア決済のレシート検証）以外でネットワーク通信を必須にしない。

## MVP 受け入れ条件

- 撮影または写真ライブラリからの読み込みで編集画面に入れる。
- 顔検出が動作し、検出した顔は既定でマスクされた状態で表示される。
- タップで個々の顔のマスクを解除 / 再マスクできる。
- 手動でマスク領域を追加・削除・移動・拡大縮小できる。
- マスクスタイルを最低 2 種類（ぼかし・モザイク）から選べる。
- 書き出し時に Exif の位置情報が確実に除去されていることを確認できる。
- 書き出しはマスクが焼き込まれた新規画像として保存され、共有シートから送れる。
- 元画像は書き出すまで写真ライブラリに保存されない。

## 対応言語

初版は日本語のみ。英語・繁体字は後続対応とする（他アプリと同様）。

## 画面・データ

画面遷移は[画面構成](./screens.md)、検出・マスキングの詳細仕様は
[検出とマスキング仕様](./detection-masking.md)、Exif・保存方針は
[プライバシーとデータ取り扱い](./privacy-data.md)を正とする。

## リスク・確認事項

検証の進め方は[技術検証計画](./tech-verification.md)にまとめる。

- オンデバイス顔検出の精度（小さい顔・横顔・逆光・多人数）。
- 車のナンバープレート検出は既製の OS 標準 API がなく、実現方式（自前モデル学習 / 既存モデルの
  流用）が未確定。
- OCR で文字は検出できても、「これは個人情報だ」という意味判定は困難。パターンマッチ（電話番号・
  郵便番号等）の精度が課題。
- マスク編集（特にフリーハンド）の操作性。
