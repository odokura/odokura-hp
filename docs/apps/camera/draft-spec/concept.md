# カメラアプリ コンセプト

## 一言でいうと

写真に写り込んだ「本人以外の人の顔」「車のナンバープレート」「住所・名前などの文字」「位置情報つきの
Exif メタデータ」を検出し、SNS 投稿や共有の前にワンタップでマスクできるカメラ / 画像編集アプリ。
すべての処理を端末内で完結し、画像や検出結果を外部へ送信しない。

## 設計の芯: 見落としより過剰マスクを選ぶ

オンデバイスの検出は完全ではない。検出漏れで個人情報がそのまま共有されるほうが、誤って必要ない
部分までマスクするより取り返しがつかない。この芯に反する仕様は入れない。

- **既定はマスクあり（opt-out）**: 検出した顔は最初からマスクされた状態で提示し、見せたい人物
  （自分の子など）だけをユーザーがタップして明示的に外す。
- **手動編集は必須の安全網**: 自動検出が見落とした部分を、ユーザー自身が塗って隠せるようにする。
  自動検出を唯一の手段にしない。
- **迷わせない**: 「撮影 / 読み込み → 確認・調整 → 書き出し」の 3 ステップに絞る。
- **端末完結**: 顔・文字・画像そのものを外部へ送らない。課金以外でネットワーク通信を必須にしない。

## 対象ユーザー

- 保育園・幼稚園・学校行事の写真を SNS や LINE で共有したい保護者（一緒に写った他の子の顔を隠したい）。
- 家や車が写った写真を投稿する際に、表札やナンバープレートを隠したい人。
- 位置情報つきの写真をそのまま SNS に上げてしまうことに気づいていない、または気にする人。
- 子どもの写真を安全に共有したい、Hatsu-go / NeteClay と同じ利用シーンを持つ人。

## ODOKURA での位置づけ

Hatsu-go（子どものことばの成長記録）・NeteClay（子どもの寝かしつけ）と同じ「子育てにまつわる情報を
安全に扱う」系列。ただし対象データは「写真」であり、撮る・共有する場面で個人情報の写り込みを
減らす役割を担う。

## 提供価値

- **ワンタップでマスク**: 検出された顔などが既定でマスクされた状態で提示され、そのまま書き出せる。
- **隠す / 見せるを選べる**: 自分の子どもなど見せたい人物だけマスクを解除できる。
- **Exif も自動で除去**: 位置情報・端末情報などのメタデータを書き出し時に取り除く。
- **手動でも塗れる**: 自動検出が拾えなかった部分を自分で隠せる。
- **端末完結**: 画像も検出結果もサーバーに送らない。

## 主要ユースケース

| ユースケース | 目的 | 優先度 |
| --- | --- | --- |
| 保育園行事の集合写真から自分の子以外の顔を隠して共有する | 他の家庭のプライバシーに配慮する | 高 |
| 家や車の前で撮った写真の表札・ナンバープレートを隠す | 自宅・車の特定を防ぐ | 高 |
| 位置情報つきの写真を Exif 除去してから SNS に投稿する | 撮影場所の特定を防ぐ | 高 |
| 自動検出が見落とした部分を自分で塗って隠す | 見落としをカバーする | 中 |
| 何枚もまとめてマスクして書き出す（バッチ） | 行事写真をまとめて処理する | 中 |

## 非目標

- 動画のリアルタイムマスキングはしない（静止画のみ）。
- 100% の自動検出は保証しない。検出はあくまで補助であり、最終確認はユーザーが行う前提とする。
- 撮影自体の高度なカメラ機能（フィルター、マニュアル露出、RAW 現像など）は目的にしない。撮影は
  最小限の機能に留め、既存の写真ライブラリからの読み込みを主経路にしてもよい。
- 顔認識による人物の同定・追跡（「これは自分の子」を記憶して自動で見分ける）は MVP では行わない。
  生体情報の保存を伴うため、採用する場合も慎重な検討が必要。
- SNS 投稿機能そのものは持たない。書き出し後は OS 標準の共有シートや写真ライブラリ保存に任せる。
- クラウドバックアップ・同期は持たない。
- 端末の写真ライブラリやクラウドバックアップにすでに同期済みの元画像を遡って保護することはできない。
  本アプリは「共有前にひと手間かける」ためのものであり、既出の画像を回収する機能ではないことを明示する。
