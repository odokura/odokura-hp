# カメラアプリ 仕様

写真に写り込んだ、本人以外の個人を特定できる情報（顔・車のナンバープレート・住所や名前などの文字・
位置情報つきの Exif メタデータ）を検出し、SNS 投稿や共有の前にマスクして安全な形に変換するカメラ /
画像編集アプリ。すべての処理を端末内で完結させ、画像や検出結果を外部へ送信しない。アプリ名は未定
（作業名: カメラアプリ）。

## 設計の芯: 見落としより過剰マスクを選ぶ

オンデバイスの検出は完全ではない。検出漏れで個人情報が漏れるほうが、誤って必要ない部分までマスクする
より取り返しがつかない。既定はマスクあり（opt-out）とし、見せたい人物だけをユーザーが明示的に
マスク解除する安全側の設計にする。詳細は[コンセプト](./concept.md)を正とする。

## 現在地

- 対象は静止画のみ。動画のリアルタイムマスキングはスコープ外とする（フレーム間追跡が必要で技術難度が高い）。
- MVP は顔検出 + 手動マスク + Exif 除去に絞る。車のナンバープレート検出と OCR による文字検出は、
  OS 標準 API がなく実現コストが未確定なため Phase 2 とし、技術検証（→ [技術検証計画](./tech-verification.md)）
  の結果を見て採否を判断する。
- 顔認識による人物の同定・記憶（「これは自分の子」を覚えて自動で見分ける）は生体情報の保存を伴うため、
  MVP では行わない。
