# 画面構成

## 方針

- 「撮影 / 読み込み → 確認・編集 → 書き出し」の 3 ステップに絞る。
- 編集画面がすべての中心。設定・購入導線は編集画面をふさがない。

## 画面遷移

```text
ホーム（撮影 or 写真ライブラリから選択）
  └→ 編集画面（自動検出 → マスク表示 → 調整）
       └→ 書き出し（Exif 除去オプション確認 → 保存 / 共有）
```

## 各画面

### ホーム

- 「撮影する」「写真を選ぶ」の 2 つの導線に絞る。
- 直近に書き出した画像の一覧を任意で表示してもよいが、表示するのは書き出し済み画像のみとし、
  マスク前の元画像は表示しない。

### 編集画面

- 検出処理中は簡潔なローディング表示にする。
- 検出完了後、顔の枠を重ねて表示する。既定ですべてマスク状態。
- 下部にマスクスタイル選択、手動マスク追加、元に戻す / やり直しを配置する。
- プレビューは常にマスク適用後の見た目を表示する。

### 書き出し画面

- Exif 除去のトグルを表示する（位置情報は既定オン固定、撮影日時・端末情報は任意）。
- 「保存」（写真ライブラリへ）と「共有」（OS 共有シート）を用意する。
- バッチ処理（有料）の場合は進捗を表示する。

### 設定

- マスクの既定スタイル、元画像の自動削除期間、購入・復元導線、規約・プライバシーポリシーを置く。
