# プライバシーとデータ取り扱い

## 原則

- 画像・検出結果・メタデータを外部（サーバー）へ送信しない。顔検出などはすべてオンデバイスの
  API / モデルを用いる。
- ネットワーク通信は課金（ストア決済のレシート検証）以外に使わない。
- クラウド同期・バックアップ機能は持たない。

権限の詳細は[要件メモ](./requirements.md)の「権限」を正とする。

## Exif・メタデータの扱い

- 書き出し時に位置情報（GPS）と端末情報（機種名など）を既定で除去する。位置情報の除去は
  既定オンから変更できないようにする（誤ってオフにして共有してしまう事故を防ぐ）。
- 撮影日時は、家族アルバムなど他アプリでの整理に使われることを考慮し、既定で保持する。除去したい
  場合はトグルで個別に除去できる。
- Exif 除去の実装が確実に機能することは[技術検証計画](./tech-verification.md)の V-2 で検証する。

## 元画像・書き出し画像の保存方針

- 撮影・読み込んだ元画像は、アプリのプライベートストレージ内にのみ一時的に保持する。写真
  ライブラリには保存しない。
- 元画像はマスク編集中の再編集のために保持するが、無期限には保持しない。書き出し完了後、または
  一定期間操作がない場合に自動的に削除する（設定で「今すぐ削除」も選べるようにする）。自動削除
  までの期間の初期値は未定（→ [決定ログ](./decisions.md)）。
- 書き出し（マスク適用・Exif 除去後）画像だけを、写真ライブラリへの保存または共有シートの対象にする。
- 元画像を誤って共有シートの対象にしない。共有シートに渡すファイルは常に書き出し後の画像のみとする。
- 書き出し画像に、マスク前の画素情報（レイヤー・サムネイル埋め込み画像など）を残さない。特に
  HEIC / JPEG のサムネイル埋め込みに注意する（→ [技術検証計画](./tech-verification.md)の V-3）。

## 限界の明示

- 端末の標準カメラアプリや他アプリで撮影し、すでに写真ライブラリやクラウドバックアップに同期済みの
  画像を遡って保護することはできない。本アプリは「共有前にひと手間かける」ためのものであり、
  既出の画像を回収する機能ではない。
- 検出は完全ではない。最終的な確認・判断はユーザーに委ねる（→ [検出とマスキング仕様](./detection-masking.md)）。
