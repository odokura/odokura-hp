# XXGGLL プライバシーポリシー

## 1. 取得する情報

- アカウントのメールアドレス、認証情報、利用状態
- Profileの表示名、性別、生年月日、国籍、ユーザーが共有を選んだ属性
- 証票、支援、決済、返金、再発行、出金、通報、同意、監査ログ
- VIP DMのメッセージ、報酬額、手数料、請求状態
- 有償VIP DMで全項目一致した場合の本人確認マーク

カード情報と口座情報はStripeが保持する。

## 2. 利用目的

- アカウント、証票、決済、出金、VIP DMを提供するため
- 属性共有、通報、返金、安全対応を行うため
- 不正利用を防止し、監査ログを保管するため

## 3. 属性共有

共有先、項目、目的への同意がある属性だけをクリエイターへ表示する。ユーザーは共有を撤回できる。譲渡時に前保有者の属性、メッセージ、支援履歴、確認マークを新保有者へ引き継がない。

## 4. 有償VIP DMの本人確認

Diditで本人確認を行い、Profileの性別、生年月日、国籍と照合する。全項目が一致した場合だけ確認マークを保存する。

XXGGLLは本人確認書類、法的氏名、Diditが返す属性、照合結果、Webhook本文、Session ID、KYC履歴を保存しない。照合後にDidit Sessionの削除を依頼し、削除失敗時だけ再試行用Session IDを短時間保持する。

## 5. 保存と第三者

- 証票、台帳、同意、確認マーク、監査ログはサービス提供、安全対応、法令上必要な期間保存する。
- 決済情報はStripe、本人確認はDiditが処理する。
- 法令に基づく場合を除き、利用者の同意なく個人情報を第三者へ提供しない。

## 6. 問い合わせ

個人情報に関する問い合わせは、サービス内の問い合わせ窓口で受け付ける。
