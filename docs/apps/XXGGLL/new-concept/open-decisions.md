# 新コンセプトの未決事項・公開条件

このページは、[コア体験](./overview.md)、[発行と参加の流れ](./support-journey.md)、
[XXGGLLとランク](./xxggll-and-ranks.md)、[金銭の流れと精算](./money-flow.md)に共通する公開条件を扱う。
以下はすべて**案**であり、販売・送金の開始条件ではない。

## 今回のコンセプトで決めた境界

- ファンは有償リクエストチケットの利用後、対象者の承認を待たずに応援ページとファーストXXGGLLを得る。
- 運営は対象者へ承認依頼、DM、参加依頼を送らない。対象者の返信、発信、コンテンツ提供、管理操作もサービスの条件にしない。
- 応援ページとXXGGLLは対象者の公認、認知、賛同を示さない。公式アカウント、肖像、投稿、グッズ、イベントを無断で掲載・販売しない。
- 金銭による応援は運営が受領し、対象者別の報酬候補として記録できる。対象者への実際の送金は、本人または正当な代理人による任意の受取登録と確認後だけに行う。
- 受取登録の有無は、発行、保有、トークン、ファンの記録を変えない。

既存の[XXGGLLコンセプト](../concept/foundation/concept.md)と関連ページは当面残す。
今回の新コンセプトとは発行条件と対象者の関わり方が異なるため、実装へ進む際は競合する仕様を改訂対象として明示する。

## 公開前に確定する取引条件

| 論点 | 公開前に決めること | 未決定の間の扱い |
| --- | --- | --- |
| 有償リクエストチケット | 税込価格、提供内容、利用期限、対象安全確認の完了後に消費すること、対象を指定した後の扱い、返金条件 | 販売しない |
| ノーマルXXGGLL | 1口1,000円（仮）の税込総額、有効期間、購入上限、追加購入、失効・返金時の扱い | 販売しない |
| 報酬候補 | 対象取引、配分式、決済手数料、税、返金・異議申立て留保、運営マージン、精算開始日 | 報酬候補を積み立てない |
| 返金 | 自己都合では返金しない条件、提供不能・誤表示・不正利用・権利申告時の判断、法令上の権利、返金後のアクセス・トークン | 購入を受け付けない |
| 受取登録・送金 | 本人・代理権・送金先の確認、受取規約、送金手数料、送金失敗、未請求報酬の期限 | 送金しない |

価格、算定式、返金条件を購入前と最終確認画面で表示できるまで、有償チケットとノーマルXXGGLLを公開しない。

## 対象者の表示と保護

対象者の承認を取らないからこそ、対象の取り違えと権利侵害を防ぐ運営上の確認が必要になる。

| 場面 | 運営の案 | 発行・販売への影響 |
| --- | --- | --- |
| 新しい対象が指定された | 同姓同名の取り違えを避ける対象識別を行い、無断利用になる素材・公式表示を含めない | 表示可否を確認するまで、公開・販売を保留できる |
| 本人・代理人・権利者から停止申告があった | 本人性・代理権・申告内容を確認し、公開表示と新規販売を速やかに止める | 既存の記録、返金、未精算報酬候補を個別確認する |
| 対象が未成年、私的個人、識別不能である | 本人保護を優先する基準を適用する | 原則として公開・販売しない。対象基準を確定する |
| 対象者が受取登録を希望する | 受取登録だけを受け付ける。発行や応援ページを承認する手続にはしない。競合する申請は一人の受取人を確定するまで保留する | 本人・代理権・送金先の確認後に精算可能額だけを案内する |

対象を指定するファン入力、応援ページに表示できる名称、異議申立て窓口、停止までの目標時間、記録保存期間は未決定である。
未決定のまま、対象者の私的連絡先の収集・利用、本人性を示す表示、肖像・投稿等の利用を行わない。

## XXGGLL、トークン、ランクの公開条件

ファーストXXGGLLは、チケット利用後に追加料金なしで発行する最初の応援記録である。
ノーマルXXGGLLは、応援ページで1口ずつ購入する関係基盤へのアクセス権であり、購入から1年間有効とする案である。

有効なXXGGLLを1口保有するごとに毎日、ファン本人のユーザーランク、保有するXXGGLLのファンランク、その対象に紐づくアイドルランクへ、それぞれ1トークンを付与する。
取消し・返金・不正無効になった口は将来のトークンを生み出さず、当該購入に由来する既付与トークンも履歴を消さない訂正記録でランクから除外する。

ファーストXXGGLLのアクセス権・有効期間、日次基準時刻、ランク閾値、降格、公開範囲、多重アカウント・自己購入・不正決済の除外基準は未決定である。
決定まで、トークン・ランクを金額、人気、対象者の評価、認知、接触権として表示しない。

## 応援記録の公開条件

ファンには、最初に応援を始めた時点と、その後の応援の来歴を残す。
金銭による応援と、応援を続けた時間は別々に記録・表示し、合算した単一の応援量として扱わない。

参加日、当時のフォロワー数、参加時の年齢、イベント参加・グッズ購入等を記録するか、どのように確認・訂正・削除・公開するかは未決定である。
決定までは、外部サービスから取得した数値、年齢、外部購入・参加の来歴を本人以外へ共有しない。

## 根拠と正本

- 既存の正本は[クリエイター報酬・精算](../app-spec/operations/creator-settlement.md)、[取引・不正・利用者安全](../app-spec/security/transactions-and-safety.md)、[コントロール](../app-spec/core/controls.md)である。本ページは新コンセプトの案であり、既存正本を変更しない。
- 通信販売における価格、支払時期・方法、提供時期、取消し条件の表示は、[消費者庁：通信販売](https://www.no-trouble.caa.go.jp/what/mailorder/)および[最終確認画面の表示例](https://www.no-trouble.caa.go.jp/pdf/20230628ac01.pdf)を確認して設計する。
- トークンを購入や値引きに使える設計にすると、前払式支払手段に該当し得る。トークンは換金、送金、譲渡、値引き、投資、配当に使わない。[金融庁：前払式支払手段](https://www.fsa.go.jp/news/27/sonota/20151214-2.html)（2026年8月20日閲覧）

これらは公開条件の安全境界を定める根拠であり、個別の法的判断を完了したことを意味しない。
有償チケット、XXGGLL販売、クリエイター報酬、送金は、公開前に特定商取引法、資金決済法、税務、本人確認、受取人との契約を専門家が確認する。

## Review response

| 項目 | 結果 |
| --- | --- |
| 対象 | 承認不要の発行、対象者保護、返金、報酬候補、受取登録、費用・運営マージン、トークン・ランク |
| 初回判定 | Revise。過去の承認・DM・アイドル管理ページの前提が新しい方針と矛盾し、対象安全確認前のチケット消費、競合する受取申請、返金後のトークン、送金結果不明時の再試行にも境界がなかった。 |
| 対応 | 承認・DM・管理操作を全ページから外し、対象者の任意の受取登録だけを独立させた。チケットは対象安全確認後にだけ消費し、受取人競合中は送金しない。返金表と報酬状態遷移表を分離し、既付与トークンの訂正、送金ID・冪等キー・結果照合、費用・マージン・報酬候補の算定境界を追加した。 |
| 修正後判定 | No unresolved P0/P1 findings。公開前の専門家確認を要する法的・会計的な決定事項は残るが、コンセプト内に承認依存、報酬の即時送金、返金後のランク保持、重複送金を許す記述を残していない。販売開始は公開前の必須条件を満たすまで行わない。 |
| 確認経路 | チケット購入、安全確認不通過、ノーマル購入、自己都合の取消希望、二重課金、権利申告、異議申立て、未請求報酬、競合する受取登録、送金失敗・結果不明、精算後の通常返金。 |
