# 新コンセプトの未決事項・公開条件

[コア体験](./overview.md)は、ファンのリクエストから始まるXXGGLLを扱う。
本ページは、その公開・実装へ進む前に確定すべき取引、安全、運用、移行の論点を扱う。

## 既存仕様との境界

既存の[XXGGLLコンセプト](../concept/foundation/concept.md)と関連ページは当面残す。
この新コンセプトは、開始点を「クリエイターによる自発的な発行」から
「ファンによる発行リクエスト」へ変える方向性を示すものであり、
本ページだけで既存のアプリ仕様、取引条件、データモデルを変更したことにはしない。

既存の発行、ランク、価格、二次流通、画面、規約と競合する部分は、
実装前に本コンセプトを起点として正本を改訂する。

## リクエストと報酬の公開条件

- リクエストには費用がかかる。無料の投票ではなく、応援意思の強さを伴う需要として集計する。
- リクエストだけではXXGGLLの保有、関係基盤へのアクセス、トークン付与は始まらない。
- アイドルが参加を承認した後、リクエストしたファンへ発行決定と購入方法を案内する。
- まだXXGGLLが発行されていないアイドルが承認した場合は、有料リクエストをしていたファンへ無償XXGGLLを発行する。
- リクエスト費用の一部は、アイドルが参加条件に同意し、報酬受領に必要な確認を終えた後、
  XXGGLLとの契約に基づくクリエイター報酬として支払う。
- 報酬はファンがアイドルへ直接送金する金銭ではなく、XXGGLLが算定・記録・精算する。

リクエスト費用の金額、課金時点、連絡を始める集計基準、辞退・無回答・重複時の取扱い、
返金条件、クリエイター報酬の割合と確定時期は未決定である。
これらを購入前に明確に表示できるまでは、有料リクエストを公開しない。

未発行かどうかは有料リクエストの確定時に判定し、承認時にはXXGGLLの発行状態への遷移と
無償XXGGLLの発行を一度だけ確定する。同じ承認の再送、並行するリクエスト、同じファンからの
重複リクエストによって、同一アイドルに対する無償XXGGLLを重複発行しない。
対象となるファンには、当該アイドルにつき無償XXGGLLを1件だけ発行する。

無償XXGGLLを受け取ったファンが関係基盤へアクセスできるか、トークンやランクの対象になるか、
有償XXGGLLへ切り替える操作を持つかは未決定である。決定まで、無償XXGGLLは発行記録として扱い、
有償XXGGLLと同じアクセス権・トークン・ランクを自動付与しない。

## 対象者保護の公開条件

対象者の情報やリクエスト件数を公開する前、または本人へ連絡する前に、
XXGGLLは同姓同名の取り違えを防ぐ対象識別と、公式の業務連絡先・所属先を確認する。
ファンが入力した私的な連絡先を使って本人へ接触しない。

本人、正当な代理人または所属先が辞退・連絡停止を求めた場合は、公開、追加連絡、再打診を停止する。
未成年者、代理権、名称・画像等の利用条件を確認できない対象には連絡・公開・発行を行わない。

対象条件、未成年者・所属先・代理権・権利確認、連絡停止の保存期間と再申請条件は未決定である。
確認できない対象への連絡・公開・発行は行わない。

## 価格・口数・トークンの公開条件

発行済みのアイドルでは、アイドル別の管理ページからXXGGLLを購入する。
価格は**1口1,000円（仮）**として構想しているが、税・手数料を含む総額、支払時期、取消し条件は未決定である。
「仮価格」のまま販売しない。

購入上限、追加購入、返金・失効時の有効口数も未決定である。
上限と取消し処理が決まるまで販売しない。

決済が有効で、取消し・返金・不正無効になっていない口だけがトークンを生み出す。
口が無効になった時点で将来の付与を停止し、誤付与は履歴を消さず訂正記録で再計算できるようにする。

日次基準時刻、1年間の暦日計算、冪等付与、訂正、累積トークンの保持期間は未決定である。
二重付与せず、再計算可能な履歴を残す。

## ランクとアカウントの公開条件

ファンランクはアカウント単位で全アイドル横断、アイドルランクはアイドル単位で全ファン横断に集計する。

ランク名称、閾値、降格、公開範囲、ランキング表示は未決定である。
金額・人気・本人評価と誤認させる表示をしない。

多重アカウント、自己購入、不正決済をランクから除外する基準も未決定である。
表示は「有効な支払いを伴うアカウント」以上の本人性を示さない。

## 設計根拠

通常の通信販売では、販売価格、支払時期・方法、権利の移転時期、取消し・返品条件などを
購入者が容易に認識できる表示が求められる。このため、リクエスト料と1口の購入代金を分け、
未決定の取引条件を残したまま課金を開始しない。

金銭の対価として発行され、物品や役務の代価に使える電子的なポイント等は、
前払式支払手段に該当し得る。新コンセプトのトークンは、購入や値引きに使えない
ランク算定用の記録に限定し、換金・送金・譲渡を認めない。

プラットフォームで受けた決済と、参加者への送金を分けて管理する方式では、
返金・異議申立て・残高不足をプラットフォーム側で扱う必要がある。
クリエイター報酬は購入者からの直接送金とせず、XXGGLLが台帳で算定・精算する。

- [通信販売広告Q&A（消費者庁・特定商取引法ガイド）](https://www.no-trouble.caa.go.jp/qa/advertising.html)
- [FinTechサポートデスク：前払式支払手段関係（金融庁）](https://www.fsa.go.jp/news/27/sonota/20151214-2.html)

これらは公開条件の安全境界を決めるための根拠であり、個別の法的判断を完了したことを意味しない。
有料リクエスト、XXGGLL購入、トークン、クリエイター報酬は、公開前に専門家の確認を受ける。

## 公開へ進むための確認

- 発行がないアイドルでは、ファンの有料リクエストを対象者ごとに集計し、個別対応を求めずアイドルへ参加を打診する。
- 発行がないアイドルが承認した場合は、リクエスト済みファンへ無償XXGGLLを発行する。
- 無償XXGGLLの発行は、承認の再送・並行リクエスト・重複リクエストでも同一ファンへ1件だけにする。
- 発行済みのアイドルでは、ファンがアイドル別の管理ページから1口以上を購入し、関係基盤へアクセスできる。
- 有効な1口につき1年間、ファンと対象アイドルのXXGGLLへ毎日各1トークンを付与する。
- 複数口では毎日の付与量だけが増え、アイドルの個別役務やファンの接触権は増えない。
- 無効な口は将来のトークンを生み出さず、誤付与を訂正記録から再計算できる。
- トークンは通貨、値引き、換金、譲渡、投資、利益保証に使わない。
- 対象者の識別・連絡先・代理権・権利を確認できず、または連絡停止を求められた場合は連絡・公開・発行しない。
- 既存コンセプトを削除せず、競合する仕様は実装前の改訂対象とする。

| 確認経路 | 通常、辞退・無回答、連絡停止、重複・不正、返金・取消し、日次再実行、既存仕様との競合 |

| 重要度 | 指摘と根拠 | 対応 |
| --- | --- | --- |
| P1 | ファン起点の指名について、なりすまし、未成年者、所属先、私的連絡先、繰り返し連絡を防ぐ境界が不足していた | 対象識別、公式連絡先、代理権・権利確認、連絡停止、確認不能時の停止を追加した |
| P1 | ファンランクが全アイドル横断か対象別か、取消し・返金・不正無効の口を集計するかが不明だった | ファンはアカウント単位の全アイドル横断、アイドルは対象単位の全ファン横断とし、有効な決済の口だけを付与対象にした。誤付与は訂正記録から再計算する |
| P2 | 「応援する人が実際に存在する」は、一意な自然人を確認した証明と誤読され得た | 「有効な支払いを伴って応援するアカウント」へ限定し、多重アカウント等は未決事項と安全側表示へ追加した |
| P1 | 発行がない状態で並行する有料リクエストや承認再送が起きた場合、無償XXGGLLの重複発行を防ぐ条件がなかった | 未発行判定、発行状態への遷移、無償発行を一度だけ確定し、同一アイドル・同一ファンには無償XXGGLLを1件だけ発行する条件を追加した |

上記の公開条件が決まるまで、有料リクエストと販売の公開gateを維持する。
