# XXGGLL クリエイター利用規約

## 1. クリエイタープロフィール

クリエイターは公開表示名を登録できる。公開表示名に連絡先やURLを含めない。

## 2. 証票とコンテンツ

- クリエイターは発行上限を設定して証票を公開できる。
- 証票の取得は、購入者ごとの承認、返信、制作、配信、発送を発生させない。
- 権利侵害、安全上の問題、誤情報があるコンテンツは停止または削除できる。

## 3. VIP DM

クリエイターはVIP DMの利用期間、送信上限、返信方針、返金方針を設定する。返信方針に記載した範囲だけを提供する。PDF契約、署名、個別条件交渉を行わない。

## 4. 報酬

クリエイター報酬は、支払い確定後に台帳へ記録し、精算可能日以降にStripe Connected Accountへ出金できる。返金・チャージバックにより確定済み報酬を回収しない。

## 5. 運営対応

運営は、通報、安全上の問題、決済上の問題に対応するため、証票、プログラム、VIP DMを停止し、返金その他の処理を行える。
