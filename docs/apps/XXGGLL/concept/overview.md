# XXGGLL 構想

XXGGLLは、クリエイターへの応援を証票と支援履歴として記録するサービスである。証票の保有はクリエイターの個別対応を約束しない。

| 領域 | 仕様 |
| --- | --- |
| 基本 | [基本設計](./foundation/overview) |
| 一般利用 | [一般ルート](./general/overview) |
| VIP | [VIP](./vip/overview) |
| 証票と追加支援 | [関係記録・追加提供](./benefits/overview) |

提供国は日本、通貨はJPYだけである。
