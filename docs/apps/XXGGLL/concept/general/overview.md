# XXGGLL 一般ルート

一般ユーザーが利用する公開ルートの正本をまとめたカテゴリです。
購入KYCとクリエイターの承認・返信・制作を必要とせず、待機、応援決済、保有、属性共有、
売却、再取得までを一連の低摩擦なライフサイクルとして扱います。

| 順番 | ページ | 確認する内容 |
|---:|---|---|

| 2 | [一般取引・証票ライフサイクル](./transaction-general.md) | 状態遷移、一次・継続支援、回収、再発行 |
| 3 | [二次流通](./secondary-market.md) | 再発行対象、参加条件、再発行時に引き継ぐ記録 |
| 4 | [価格・発行数](./pricing.md) | AI算出、クリエイター設定、希少性の調整 |
| 5 | [一般クリエイター](./creator-general.md) | 公開前の一回設定と販売後に行わないこと |
