# 一般ユーザーとの関係

ユーザーは証票を保有して、支援履歴と同意した属性共有を管理する。

| 状態 | 証票 | 属性共有 |
| --- | --- | --- |
| 継続中 | 保有・表示・再発行できる | 有効な同意だけを共有する |
| 継続停止 | 保有・再開・再発行・返還できる | 共有を停止する |
| 再発行 | 新保有者へ証票番号と来歴を引き継ぐ | 前保有者の情報を引き継がない |
| 返還 | 証票を回収する | 共有を停止する |
| プログラム終了 | 支払済み期限まで保有し、満了後は終了済みとして保持する | 新しい共有を停止する |

証票の保有は、クリエイターの閲覧、返信、面会、制作、物品提供を保証しない。
