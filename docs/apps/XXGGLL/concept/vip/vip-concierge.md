# VIPコンシェルジュ運用

本ページは、VIP・ExtraVIPユーザーと運営のコミュニケーション、属性・希望の受け取り方、
クリエイターへの共有、ExtraVIP調整を扱う**コンシェルジュ運用の正本**である。

## 目的

コンシェルジュは、クリエイター本人との私的な窓口ではない。運営が次を引き受けることで、
ユーザーの希望を安全に受け取り、クリエイターの個別対応負担を最小にする。

- 信頼・安全審査
- 属性・希望の整理と同意管理
- VIPの集計ダッシュボードの維持
- VIP・ExtraVIP役務の匿名打診と条件調整
- 進捗通知、記録、通報、担当変更

信頼関係は、担当者との私的な親密さではなく、担当の継続性、説明の一貫性、共有前の同意、
記録、期限の明示によって作る。

## 連絡手段

- VIP・ExtraVIP招待承諾後、アプリ内に運営との専用スレッドを開設する。
- 主担当と副担当を設定し、担当不在時も運営記録から引き継げるようにする。
- 相談、確認、同意、共有、見送り、契約状況を同じスレッドへ記録する。
- 運営担当者やクリエイターの個人SNS、私用連絡先、外部DMを使わない。
- VIP・ExtraVIP役務で外部会場等が必要な場合も、正式な連絡経路を運営が記録する。

## 初回案内

専用スレッドの開始時に次を固定表示する。

- VIP取得はクリエイターの閲覧、返信、面会、制作、役務を保証しない
- 個別役務の相談でクリエイターへ渡す情報は、契約テンプレートが列挙した項目からユーザーが選ぶ。この選択は通常プロフィールの共通共有設定を変更しない
- 法的氏名、住所、本人確認書類、決済情報は原則共有しない
- 通常の属性・希望共有とVIP・ExtraVIPの役務相談は別の手続きである
- VIP・ExtraVIPとも、最終合意と別決済前はクリエイターに役務義務がない
- VIP・ExtraVIP XXGGLLの購入と役務相談開始に本人確認は不要である
- 法令上の本人確認が必要な対象コンテンツ・役務は提供しない
- 通常応答時間、緊急通報、担当変更、相談取下げ、同意撤回の方法

## 希望の受け取り

自由記述だけに依存せず、次の構造化フォームで受け取る。

| 項目 | 内容 |
| --- | --- |
| 対象 | 希望するクリエイターまたは活動 |
| 応援理由 | 何に共感し、何を応援しているか |
| 共有属性 | 年代、地域、職業・業界、興味、活動歴等から選択 |
| 知ってほしいこと | クリエイターへ届けたい要約。280文字以内 |
| 期待しないことの確認 | 閲覧、返信、面会、制作を保証しないことへの同意 |
| NG条件 | 避けたい表現、連絡手段、時間帯 |
| 個別役務相談 | VIP・ExtraVIPで役務を希望する場合だけ、目的、時期、予算、回数 |

VIPでは「実現してほしい依頼」として扱わず、属性・応援意思の共有として受け取る。
実現を求める内容は個別役務相談へ分け、通常のVIPダッシュボードへ要求として載せない。

## VIP共有フロー

1. ユーザーが共有項目と対象クリエイターを選ぶ。
2. 運営が連絡先、機微情報、要求表現、禁止内容を自動検査する。
3. ユーザーが実際の共有内容と「返信を保証しない」旨を確認して同意する。
4. 運営がクリエイターの受入設定に合う項目だけを集計ダッシュボードへ反映する。
5. クリエイターは任意で集計・個別プロフィールを閲覧する。
6. 閲覧状況と返信状況はユーザーへ表示しない。

クリエイターへのリアルタイム通知、個別の受領確認、返信期限は設けない。ユーザーは共有内容を
いつでも撤回でき、撤回後は以後の表示から削除する。

## VIP・ExtraVIP役務調整

VIP・ExtraVIPの個別役務を相談する場合は次の順序を守る。

1. 運営が目的、予算、回数、期間、禁止条件を整理する。
2. 氏名、連絡先等を除き、匿名条件でクリエイターへ実現可能性を確認する。
3. クリエイターが14日以内に検討可能・見送りを選ぶ。無回答は見送りとして終了する。
4. 検討可能な場合、運営が提供内容、価格、期限、取消、返金、権利、安全条件の案を作る。
5. ユーザーが共有項目と条件案へ同意する。
6. クリエイターが最終条件へ応諾する。
7. 別決済後に役務契約を成立させる。

見送りの場合、ユーザーを責める表現やクリエイターの非公開事情を開示しない。理由は
「対応枠なし」「条件不一致」「安全・規約上対応不可」「理由非開示」の区分だけを通知する。

## 共有しない情報

次は、役務履行で法的に必要かつユーザーが都度同意した場合を除き、クリエイターへ共有しない。

- 法的氏名、生年月日、正確な住所、本人確認書類
- 電話番号、個人メールアドレス、SNS ID
- 決済手段、金融口座
- 他クリエイターとの取引履歴
- VIP・ExtraVIPの詳細な内部審査情報
- 紹介者の非公開情報
- 撤回済み属性、過去の相談、見送り履歴

累計支援は正確な金額ではなく支援額帯を既定表示とする。ExtraVIP価格算出等で正確な金額が
必要な場合も、まず運営内で使用し、クリエイターへ共有する必要性を個別確認する。

## 状態表示

| 状態 | 意味 |
| --- | --- |
| 受付済み | 運営が相談を受け付けた |
| 内容確認中 | 不足項目・禁止内容・共有範囲を確認している |
| 同意待ち | ユーザーが共有内容または条件を確認している |
| 共有反映済み | ダッシュボードの集計表示に反映され、クリエイターがいつでも確認できる |
| 匿名打診中 | VIP・ExtraVIP役務の条件を匿名で確認している |
| 条件調整中 | VIP・ExtraVIP役務の価格・期限・取消等を調整している |
| 最終応諾待ち | 双方の最終確認を待っている |
| 契約成立 | 別決済が完了し役務契約が成立した |
| 見送り・取下げ | 今回の調整を終了した |

## 応答基準

- 新規相談の受付確認: 1営業日以内
- 通常質問への一次回答: 2営業日以内
- VIP共有内容の修正・撤回: 1営業日以内
- VIP・ExtraVIP役務の匿名打診: クリエイターへ送付後14日以内
- 個人情報漏えい、脅迫、つきまとい等の緊急申告: 24時間受付、即時アクセス停止を可能にする

通常の属性・希望共有にクリエイターの応答時間を設定しない。VIP・ExtraVIP役務の匿名打診だけ
14日とし、無回答で自動見送りにする。

## 記録と安全

- 希望、同意、撤回、共有先、共有日時、閲覧権限、ExtraVIP条件を監査ログへ残す。
- クリエイター・提供者の閲覧権限を最小化し、不要になった権限を停止する。
- 性的サービス、交際、私的連絡先交換、無制限対応、違法・危険行為を仲介しない。
- ユーザーの同意なしに希望や審査情報を広告・営業へ転用しない。
- 通報・紛争対応は運営が窓口となり、ユーザーとクリエイターの直接交渉を必須にしない。

保存期間、削除請求、第三者提供、VIP・ExtraVIP契約記録の法的要件は、
実装前に法務・プライバシー
レビューを行って最終確定する。
