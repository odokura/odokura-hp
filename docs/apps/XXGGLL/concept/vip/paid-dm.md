# VIP DM

VIP DMは、VIPがクリエイターへ送るアプリ内メッセージである。DMの開始料金は0円で、利用者が各メッセージに設定したクリエイター報酬だけを翌月請求する。

## 利用の流れ

1. クリエイターが、利用期間・送信上限・返信方針・返金方針を設定してDMを公開する。
2. VIPが利用条件に同意して、0円でDMを開始する。
3. 0円のメッセージはそのまま送信できる。
4. 報酬額を付ける場合だけ、本人確認の確認マークと翌月請求用カードを必要とする。
5. 月末に利用者ごとの報酬額と手数料を集計し、翌月にStripe Invoiceで請求する。
6. 請求成功後、クリエイター報酬を台帳へ計上する。

## 金額

- 通貨は日本円だけを使う。
- 報酬額はメッセージごとに利用者が0円から10,000,000円の整数で設定する。
- 手数料は利用者負担。パターンはA=10%、B=15%、C=20%、D=30%で、金銭が発生する機能はDを既定にする。
- 返金時の決済手数料はXXGGLLが負担する。

外部連絡先、直接取引、性的内容、交際目的、脅迫、勧誘は禁止する。DMは契約書・署名・個別条件交渉の機能ではない。
