# XXGGLL VIP・ExtraVIP

運営招待を伴う非公開ルートをまとめたカテゴリです。VIP・ExtraVIPとも、XXGGLL取得だけでは
役務を発生させず、双方合意と別決済による個別契約で役務を追加できます。

## 位置づけ

- VIP・ExtraVIP取得では、クリエイターの返信・制作・面会義務は発生しません。
- ExtraVIPはVIPからのエスカレーションに加え、紹介・コネクション等を起点とする特殊ルートを含みます。
- 個別役務はVIP・ExtraVIPで双方が最終応諾し、必要時の条件付きKYCと別決済が完了した場合だけ発生します。
- 公開取引の共通処理は、[一般ルート](../general/overview.md)を正本とします。
