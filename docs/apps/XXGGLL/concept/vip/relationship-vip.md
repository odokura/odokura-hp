# VIPユーザーとの関係

VIPユーザーは、表示された利用条件に同意して0円でVIP DMの利用権を開始できる。

- 0円のメッセージは本人確認とカード登録なしで送信できる。
- 報酬額を付けるメッセージには、本人確認の確認マークと翌月請求用カードが必要である。
- 期限、送信上限、返信方針、返金方針はDMごとに適用する。
- 前月分の請求が未払いの場合、報酬額を付けるメッセージを送信できない。
- クリエイターはVIPユーザーの個人情報、本人確認書類、照合結果を閲覧できない。
