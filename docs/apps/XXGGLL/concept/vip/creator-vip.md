# VIPクリエイター

本ページは、VIPクリエイターの招待・認定、VIP受入設定、ExtraVIP打診への対応を扱う。
一般向けの作業と責任は[一般クリエイター](../general/creator-general.md)を適用する。

## 定義

VIPクリエイターは、上級認定クリエイターのうち、運営の総合評価により招待され、招待を承諾した
正規提供者である。申請による自動審査や課金による購入はできない。

VIP認定は、すべての支援者へ個別対応する義務ではない。VIP XXGGLLの取得でも、クリエイターによる
閲覧、返信、面会、制作、役務は発生しない。VIP・ExtraVIPとも、個別応諾、
別決済を経た役務契約が成立した場合だけ役務が生じる。

## 招待基準

運営は最低12か月の実績を使い、次を総合評価する。

- 一次発行、継続支援、二次流通ロイヤリティの取引額と健全性
- 支援者の継続率と不正・返金・チャージバック率
- 価格、発行上限、証票表示、任意固定コンテンツの説明の正確性
- 知的財産権、規約、法令、安全基準の順守
- 通報、アカウント侵害、重要な運営連絡への対応
- 属性情報を持ち出し・営業・私的連絡へ使っていないこと
- VIP受入上限を設定し、VIP・ExtraVIP役務打診の可否を判断できる運営体制

コンテンツの定期履行実績は評価項目にしない。XXGGLL本体に定期役務がないためである。

候補抽出は四半期ごと、招待の有効期限は30日とする。招待辞退後は12か月経過するまで再招待しない。
認定は12か月ごとに更新確認し、重大違反時は期間途中でも停止・取消できる。

## 既存VIPクリエイターの移行

既存仕様上のVIPクリエイターは、移行時に**上級認定クリエイター**へ設定する。新しいVIPへ
自動移行しない。12か月分の新基準に相当するデータがない場合は、移行後6か月の実績を確認してから
招待可否を判断する。

## VIP受入設定

VIPクリエイターは四半期ごとに次を設定する。

| 項目 | 設定内容 |
| --- | --- |
| 受入上限 | 四半期内に新規発行できるVIP証票数 |
| 発行上限 | 同時に有効にできるVIP証票総数 |
| 価格モード | AI自動価格または任意価格 |
| 属性カテゴリ | 年代、地域、職業・業界、興味、活動歴等から受け取る項目 |
| 自由記述 | 280文字メッセージを受け取るか |
| 個別役務 | VIP・ExtraVIPの匿名打診を受ける・当面受けない |
| 任意固定コンテンツ | 完成済み素材を最大3件登録するか |

受入上限内では、運営とAIが需要・資格を確認してVIP証票を発行する。クリエイターはユーザーごとの
発行承認を行わない。受入上限を0にすると新しいVIP発行を停止できるが、既存保有者の証票と
継続支援には影響させない。

## VIP・ExtraVIP XXGGLL取得だけでは行わないこと

- 招待候補や購入者を一人ずつ承認する
- 個別プロフィールやメッセージを必ず閲覧する
- 受領確認、既読、返信、リアクションを返す
- 定期投稿、個別制作、物品、優先案内、割引、イベント枠を提供する
- 本人確認書類、住所、連絡先、審査詳細を閲覧する
- VIPであることを理由に私的連絡や面会へ応じる

VIPダッシュボードの未閲覧や無返信を、認定取消やユーザーへの不利益に使わない。
次の役務を提供する場合は、通常のXXGGLL運用から分離し、本ページの匿名打診と個別契約を経る。

## VIP・ExtraVIP役務の匿名打診

個別役務打診を「受ける」に設定した場合だけ、運営はVIP・ExtraVIPユーザーの匿名条件を送る。

- 最初の打診ではユーザーを特定できる情報を含めない。
- クリエイターは14日以内に「検討可能」または「見送り」を選ぶ。
- 無回答は自動見送りとし、督促は1回だけ運営が行う。
- 見送り理由の詳細入力は任意とする。
- 検討可能を選んでも役務義務は発生しない。
- ユーザーの共有同意と最終条件案を確認した後、最終応諾した時点で別決済へ進む。
- 法令上の本人確認が必要な対象コンテンツ・役務は提供しない。
- 別決済完了後に限り、合意した範囲の役務義務が発生する。

条件整理、同意、通知は[VIPコンシェルジュ運用](./vip-concierge.md)、役務境界は
[任意提供・個別役務](../benefits/templates.md)を正本とする。

## 属性情報の取扱い

- VIP属性は運営画面内で閲覧し、CSV・外部CRMへの持ち出しを既定で許可しない。
- クリエイター本人だけでなく、事務所・提供者の閲覧者にも最小権限と監査ログを適用する。
- 購入者向けの本人確認は行わず、法的氏名、本人確認書類、正確な住所、私的連絡先は表示しない。
- 属性を差別、購入拒否、外部営業、私的連絡、第三者提供に使わない。
- ユーザーの撤回後は画面の集計表示から削除する。
- 問題のあるメッセージは返信せず、非表示・通報して運営へ引き継ぐ。

## 停止・取消

次の場合、運営はVIPの新規発行、属性閲覧、ExtraVIP打診を停止できる。

- 本人・正規提供者・精算先の確認が失効した
- 属性情報の持ち出し、目的外利用、漏えいが疑われる
- 重大な規約違反、権利侵害、不正取引がある
- 重要な安全確認へ30日以内に応答しない
- クリエイター本人または提供者がVIP認定を辞退する

停止・取消後も、既存証票をただちに回収しない。プログラムを継続するか終了するかを運営が確認し、
終了する場合は一般のプログラム終了ルールを適用する。成立済みVIP・ExtraVIP役務は別契約に従って
履行、代替、返金を処理する。
