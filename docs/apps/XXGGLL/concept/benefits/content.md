# 関係記録・コンテンツ

証票は支援関係を記録する。証票にはランク、番号、発行元、保有状態、来歴、証票支援額の累計を記録できる。

- 支援履歴は保有者本人だけが確認できる。
- 属性共有はユーザーが同意した項目だけをクリエイターへ共有する。
- 表示名、応援理由、関心タグ、自由記述はユーザーが設定できる。
- 法的氏名、住所、本人確認情報、決済情報、前保有者の属性と支援履歴は証票に記録しない。
- 再発行時に前保有者の個人情報とメッセージを引き継がない。
- 証票支援は証票の累計額を更新するが、クリエイターの個別作業を発生させない。
