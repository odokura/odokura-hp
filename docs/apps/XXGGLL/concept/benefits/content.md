# 関係記録・コンテンツ

本ページは、XXGGLLとして記録・保有するものと、運営またはユーザーが生成するコンテンツを扱う
**関係記録・コンテンツの正本**である。すべてのランクで、XXGGLL取得だけによるクリエイターの
制作、更新、返信、配信を前提にしない。

## コンテンツ体系

| 層 | 内容 | 主体 | クリエイターの販売後作業 | 譲渡 |
| --- | --- | --- | --- | --- |
| 関係証票 | 番号、対象クリエイター、ランク、発行日、来歴、現在状態 | 運営 | なし | 引き継ぐ |
| 個人支援記録 | 一次支援、継続支援、支援期間、ロイヤリティ寄与 | 運営 | なし | 引き継がない |
| 証票支援 | 保有者が証票へ追加で支払う任意の支援額の累計 | ユーザー | なし | 引き継ぐ |
| 応援表現 | 表示名、応援理由、関心タグ、280文字以内のメッセージ | ユーザー | 閲覧・返信義務なし | 引き継がない |
| 属性共有 | 年代、地域、職業・業界、興味、活動歴等の同意済み項目 | ユーザーと運営 | 閲覧・返信義務なし | 引き継がない |
| 保有体験 | 証票画像、バッジ、コレクション、支援タイムライン、継続記念 | 運営 | なし | 証票固有部分だけ引き継ぐ |
| 任意固定コンテンツ | 事前登録済みの画像、音声、動画、共通メッセージ | クリエイター | なし | 公開時に定めた範囲で引き継ぐ |

「ユーザーが応援を所有する」とは、証票を保有し、自分の支援履歴を継続的に確認できることを指す。
クリエイターの著作権、個人的な認知、返信を所有することではない。

## ランクごとの既定内容

| ランク | 運営が提供する既定内容 | クリエイター役務 |
| --- | --- | --- |
| 無料 | 関係開始証票、基本バッジ、属性共有 | なし |
| 一般 | 有料支援証票、支援履歴、継続記念、属性共有 | なし |
| 上級 | 一般の全機能、希少性表示、強化された証票デザイン | なし |
| 最上級 | 上級の全機能、最上位支援表示 | なし |
| VIP | 非公開証票、詳細プロフィール・希望共有。別契約成立時だけ個別役務を追加 | 契約した範囲だけ |
| ExtraVIP | 非公開証票、特殊紹介記録。別契約成立時だけ個別役務を追加 | 契約した範囲だけ |

価格差はクリエイターコンテンツの品質や量ではなく、支援額、希少性、証票表示、関係記録上の
位置づけで説明する。

## 証票に記録する項目

- 証票IDと通し番号
- 対象クリエイターと正規提供者
- XXGGLLランク
- 初回発行日時
- 現在の保有開始日時
- 継続支援中・停止中・終了済み等の状態
- 新規発行、譲渡、回収、終了の来歴
- クリエイターが設定した発行上限
- 任意固定コンテンツの有無、権利、譲渡時の閲覧可否
- 証票支援額の累計（匿名化した合計額のみ。後述の「証票支援」を正本とする）

法的氏名、住所、本人確認情報、前保有者の属性、支援額、退出理由は証票へ記録しない。証票支援額の累計は
この例外とし、個別の支援者・日時・金額の内訳は証票へ記録しない。

## 個人支援記録

ユーザーのアカウントには次を分けて記録する。

| 区分 | 支援額として扱うか |
| --- | --- |
| 一次発行のクリエイター受取対象額 | 扱う |
| 継続支援のクリエイター受取対象額 | 扱う |
| 二次流通時のクリエイターロイヤリティ | 扱う |
| 証票支援として自分が支払った額 | 扱う |
| 二次流通時に前保有者へ付与する再発行クレジット | 扱わない |
| プラットフォーム手数料、税、決済手数料 | 支援額と分けて表示する |

二次取得者の保有期間と支援履歴は取得成立時から始める。前保有者の履歴を合算しない。

## 証票支援

証票支援は、保有者が保有中の証票へ追加で支払える任意・反復可能な支援決済である。個人支援記録と異なり、
支払った額の累計は証票そのものの記録として残り、二次流通で証票とともに新しい保有者へ引き継がれる。

- 対象は二次流通可能なランク（一般・上級・最上級・VIP）に限る。無料は譲渡できないため対象外、ExtraVIPは
  個別関係に紐づき譲渡できないため対象外とする（[取引ルール](../general/transaction-general.md)、
  [VIP・ExtraVIPユーザーとの関係](../vip/relationship-vip.md)）。
- 決済可能な最低金額以上で、保有中いつでも何度でも行える。上限は設けない。
- 一次購入・継続支援と同様、証票支援に本人確認を要求しない。
- メッセージは添付できない。証票支援だけでは、クリエイターに個別の応答・確認・リアクションを要求せず、
  証票支援を理由にクリエイターへ何らかの作業を発生させない。
- クリエイター報酬は、購入価格・運営売上との配分率を約定せず、取引ごとに運営が算定する
  （[取引ルール](../general/transaction-general.md)）。
- 支払った額は、支払った本人の個人支援記録（自分の統計表示用。譲渡時は引き継がない）と、証票側の累計額
  （証票の記録。譲渡時は証票とともに引き継ぐ）の両方に記録する。証票側に記録するのは匿名化された合計額
  だけとし、誰がいつ何円支援したかという個別の履歴は証票へ記録しない。
- 累計額の蓄積は、転売時の価格上昇や収益を保証するものではない。あくまで応援の記録の厚みを表す指標であり、
  投資商品としての性質を持たせない。

## 応援表現

- 表示名、定型の応援理由、関心タグ、280文字以内の自由記述を利用できる。
- URL、電話番号、メールアドレス、SNS ID等の私的連絡先は入力・共有できない。
- 差別、脅迫、性的要求、面会要求、個人情報、なりすましを自動検知と通報対象にする。
- メッセージを送信しても、既読、閲覧状況、返信状況をユーザーへ表示しない。
- クリエイターは個別メッセージを開く義務を負わず、運営はダッシュボードでの集計表示を既定にする。

属性共有は[属性開示・決済事業者確認](../foundation/identity-disclosure.md)を正本とする。

## 任意固定コンテンツ

クリエイターは、販売開始前に完成済みの素材を任意で1ランクにつき最大3件登録できる。

- 登録しなくてもすべてのランクを発行できる。
- 購入者ごとの差し替え、名前入れ、個別制作は行わない。
- 公開後の定期更新、追加投稿、最低投稿回数を約束しない。
- 運営はファイル配信、番号等の自動差し込み、アクセス制御を行う。
- クリエイターは配信・表示・譲渡に必要な権利と利用期間を公開前に確認する。
- 権利侵害や安全上の理由で停止する場合、証票自体は維持し、停止理由と影響範囲を表示する。

固定コンテンツはXXGGLL価格の対価の中心として表示しない。個別役務や物品等は
[コンテンツ・追加商品・個別サービス](./templates.md)へ分離する。

## 譲渡・継続停止・終了

- 証票番号、発行日、来歴、証票固有の運営生成表示は買い手へ引き継ぐ。
- 証票支援額の累計は証票とともに買い手へ引き継ぐ。前保有者ごとの個別の支援内訳は引き継がない。
- 前保有者の支援履歴、属性、メッセージ、公開設定は引き継がない。
- 任意固定コンテンツは、公開時に譲渡可能と表示したものだけ買い手も閲覧できる。
- 継続支援停止後も証票と個人の支援履歴は保持し、証票には非継続となった時刻と状態を残す。継続支援とプロフィール項目の開示は停止する。
- プログラム終了後も証票と来歴は保持し、新しい支援決済と属性共有を停止する。

状態遷移は[取引ルール](../general/transaction-general.md)を正本とする。

## 安全・権利

- クリエイターまたは提供者は、必要な権利を持つ固定コンテンツだけを登録する。
- 証票の譲渡は、固定コンテンツの著作権移転を意味しない。
- 成人向け表現、第三者の肖像、外部サービス誘導は運営の事前審査対象とする。
- 応援表現と固定コンテンツは、公開前の自動検査と通報後の人手調査を併用する。
- ファイル形式、容量、保存期間は実装設計で定めるが、販売後のクリエイター作業を必要とする方式は
  採用しない。
