# ランク・発行上限

## 証票ランク

| ランク | 利用方法 |
| --- | --- |
| `free` | 無料証票 |
| `standard` | 有料証票 |
| `advanced` | 有料証票 |
| `elite` | 有料証票 |
| `vip` | VIP証票 |
| `extravip` | ExtraVIP証票 |

各発行プログラムは発行上限を持つ。発行済み証票と有効な仮押さえの合計は上限を超えない。

## ユーザーランク

| ランク | 内容 |
| --- | --- |
| `general` | 通常ユーザー |
| `vip` | VIP DMを利用できるユーザー |
| `extravip` | ExtraVIPユーザー |

VIP DMは`vip`ユーザーが利用できる。証票ランクとユーザーランクは別に管理する。
