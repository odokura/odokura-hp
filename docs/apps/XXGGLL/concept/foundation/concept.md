# XXGGLL コンセプト

XXGGLLは、ユーザーのクリエイターへの応援を、公式プログラム上の支援関係として記録するサービスである。取得・保有・表示できる番号付きデジタル証票を提供するが、証票の取得だけでクリエイターの個別対応や役務は発生しない。

## 原則

1. 証票、支援履歴、保有表示、同意した属性共有を提供する。
2. 証票は譲渡できるが、前保有者の属性、メッセージ、本人情報、支援履歴は譲渡しない。
3. クリエイターの作業を保有者数に比例させない。個別返信、定期制作、発送、常時応答を証票の対価に含めない。
4. 属性共有は接触権ではない。閲覧・返信・面会は保証しない。
5. VIP DMは証票と別のアプリ内機能とする。開始は0円で、報酬額を付けたメッセージだけを翌月請求する。

## 本人確認と安全

通常の登録、証票の取得・購入・保有・譲渡にKYCは要求しない。Diditによる本人確認は、有償VIP DMだけで使う。書類・属性値・照合結果は保存せず、全項目一致時の確認マークだけを残す。

VIP DMでは、外部連絡先、直接取引、性的内容、交際目的、脅迫、勧誘を扱わない。PDF契約、署名、個別条件交渉の機能も提供しない。

## サービスの境界

- 日本・日本円だけを対象にする。
- 通常のデータベースで管理し、NFT・暗号資産を使わない。
- 証票は物品、株式、配当商品、利回り商品ではない。
- 値上がり、買戻し、元本、流動性、収益を保証しない。
