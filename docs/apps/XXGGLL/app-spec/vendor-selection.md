# XXGGLL ベンダー選定

本ページは、決済・クリエイター報酬の受取・ホスティング/DBについて、実在するサービスの比較と選定方針を定める。
利用者向けの本人確認ベンダーは採用せず、法令上の本人確認が必要な対象コンテンツ・役務は提供しない。

## 調査時点の注記

料金・仕様情報は契約前に各社の公式情報で再確認する。正式な単価が非公開の項目は、憶測で補わず見積もりを取得する。

## 決済代行・報酬受取

### 比較した候補と除外理由

| 候補 | 状況 |
| --- | --- |
| Stripe Connect | 採用候補。ホスト型オンボーディングとSeparate Charges and Transfersを利用する |
| PAY.JP Platform | 比較対象。プラットフォーム向け費用・送金経路は要問い合わせ |
| KOMOJU Platform | 比較対象。マーケットプレイスの送金条件・費用は要問い合わせ |
| GMOペイメントゲートウェイ | 一次審査・二次審査を伴う正式契約が前提で、小規模運用には重い。除外 |
| Univapay | マーケットプレイス型の分割入金に関する公開情報が乏しい。除外 |

| 項目 | Stripe Connect | PAY.JP Platform | KOMOJU Platform |
| --- | --- | --- | --- |
| 決済手数料 | カード決済成功ごと3.6%（契約前に再確認） | プランごとに変動 | 決済手段ごとに変動（要問い合わせ） |
| プラットフォーム側の固定費 | Connected Accountの入金・送金条件に応じて発生 | 非公開（要問い合わせ） | 非公開（要問い合わせ） |
| 送金・入金手数料 | 契約・送金経路により変動 | 振込手数料等を確認 | 返金・決済手段ごとの手数料を確認 |
| 受取側の確認 | Stripeのホスト型オンボーディング | 事業者・テナント審査の要否を確認 | Seller/Payout Merchantの手続を確認 |

### 選定方針: Stripe Connect（Separate Charges and Transfers）

購入者の支払いはいったんXXGGLLのStripeプラットフォーム残高へ入り、`ledger_entry`へクリエイター報酬を記帳する。
通常は決済確定日から90日経過後、クリエイターが`payout_request`を申請した時点でConnected Accountへの送金を行う。
クリエイターの本人確認・事業者確認・振込先確認・Stripeサービス契約同意は、Stripeのホスト型オンボーディングで
Stripeが実施する。XXGGLLは本人確認書類や銀行口座情報を受領・保存しない。

Connected Accountはクリエイター報酬の精算専用とする。購入者からの直接支払い、二次流通の前保有者への現金送金、
再発行クレジットの現金化には使わない。Stripeが送金可と判定した国・通貨・経路だけを受け付け、対象外の代替送金は行わない。

### 選定理由と留意点

- 購入と報酬送金のタイミングを分離でき、少人数運用でも扱いやすい。
- オンボーディング・本人確認・口座確認をStripeへ委ね、XXGGLL側の書類管理をなくせる。
- PaymentIntentsのオーソリ→キャプチャで15分の在庫仮押さえを実装できる。
- C2C的なマーケットプレイスの審査、プラットフォーム残高の保持期間、返金・チャージバック、送金国・通貨は契約前にStripeへ確認する。
- Stripeが送金不可と判定したConnected Accountへ、銀行振込等の代替送金は行わない。

## ホスティング / DB

| 項目 | Railway | Render | Supabase | Fly.io |
| --- | --- | --- | --- | --- |
| 特徴 | アプリとマネージドPostgresを1プロジェクトで運用 | WebとPostgresを別サービスで運用 | Postgres・Auth・Storageをまとめて提供 | マルチリージョンが主眼 |
| 小規模費用の目安 | Hobby月$5〜（契約前に再確認） | Web/Postgresの各プラン | 無料枠・Proプラン | 従量課金 |
| 運用負担 | 低い。CLIとGitでデプロイ | 低い | Auth/Storageの学習コストが増える | DB運用の責任が大きい |

### 選定方針: Railway（アプリ本体 + マネージドPostgreSQL）

単一モノリスとPostgreSQLを同一プロジェクトで運用でき、少人数で扱える。バックアップ・リストア、ログ、環境分離を
実機で確認し、運用要件を満たせない場合はRenderを再評価する。

## 未確定事項・次アクション

- Stripe Connectの日本向け利用規約、マーケットプレイス審査、Separate Charges and Transfersを確認する。
- 対応国は当面日本、通貨はJPYとし、海外対応はStripeの有効判定を確認してから別途決定する。
- 出金申請時のConnected Account作成、ホスト型オンボーディング、`account.updated`反映、Transfer、返金を実機検証する。
- 15分仮押さえ、プラットフォーム残高の保持期間・リザーブ、決済手数料と返金時負担を確認する。
- Railwayのデプロイ、PostgreSQLバックアップ、テスト環境分離を実機確認する。
