# XXGGLL 画面・コンソール構成

| 利用者 | 画面 | 内容 |
| --- | --- | --- |
| 全員 | ホーム | サービス案内と各機能への導線 |
| 全員 | アカウント | 登録、ログイン、セッション管理 |
| ユーザー | 無料・有料証票 | 証票の一覧、予約、購入、保有、継続、返還、再発行 |
| ユーザー | VIP DM | DM枠、利用権、メッセージ、報酬額、月次請求、本人確認、通報 |
| クリエイター | クリエイター | 公開表示名、無料証票、VIP DMの作成 |
| クリエイター | VIP DM受信箱 | 自分のDMに紐づく利用権とメッセージ |
| 管理者 | 運用管理 | 台帳、証票、プログラム、通報、VIP DM、返金、手数料、監査ログ |

本人確認は有償VIP DMの画面から始める。Profileに性別・生年月日・国籍を初回入力し、全一致時の確認マークだけを表示する。
