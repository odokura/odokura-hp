# XXGGLL セキュリティ

## 認可と監査

- サーバー側で認証、アカウント状態、所有者、管理者権限を検証する。
- 管理操作、決済状態、証票状態の変更を監査ログへ記録する。
- 監査ログは更新・削除できない。

## 個人情報とKYC

- 属性共有は同意済みの項目だけを共有する。撤回後は表示対象から外す。
- KYCは有償VIP DMだけで行う。
- 本人確認書類、法的氏名、返却属性、照合結果、Webhook本文、Session ID、KYC履歴を保存しない。
- Profileの性別、生年月日、国籍は初回入力後に変更しない。全一致時だけ確認マークを保存する。
- Didit Sessionは照合後に削除し、失敗時だけ再試行する。

## 決済と安全

- カード・口座情報はStripeだけが保持する。
- 署名検証済みWebhookだけで決済とKYCの状態を変更する。
- 同じWebhookは重複処理しない。
- 送金はJP・JPYの許可経路だけで実行する。
- VIP DMでは外部連絡先、直接取引、性的内容、交際目的、脅迫、勧誘を拒否する。
- 通報、停止、返金は管理者が処理する。
