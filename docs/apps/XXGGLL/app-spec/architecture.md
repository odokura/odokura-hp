# XXGGLL アーキテクチャ

## 構成

- Next.jsがWeb画面とサーバーAPIを提供する。
- PostgreSQLが証票、台帳、同意、Profile確認マーク、監査ログを保持する。
- RailwayがアプリケーションとDBをホストする。
- Stripeが決済、カード保存、クリエイター送金を処理する。
- Diditが有償VIP DMの本人確認を処理する。

## 境界

- カード番号、銀行口座番号、本人確認書類はアプリケーションDBに保存しない。
- StripeとDiditの秘密鍵、Webhook署名鍵はサーバー側環境変数だけに設定する。
- KYCの照合値、照合結果、Webhook本文、Session ID、履歴は保存しない。削除失敗時だけ再試行用Session IDを短時間保持する。
- Web APIは認証、所有者確認、管理者権限をサーバー側で検証する。

## 主なモジュール

| モジュール | 役割 |
| --- | --- |
| 認証 | アカウント作成、ログイン、セッション |
| 証票 | 発行、保有、継続、返還、再発行 |
| 決済・台帳 | Stripe連携、決済結果、クリエイター報酬、出金 |
| 属性共有 | 項目別同意、撤回、集計表示 |
| VIP DM | DM枠、利用権、メッセージ、月次請求、通報、返金 |
| 運用 | 通報、停止、返金、監査ログ |
