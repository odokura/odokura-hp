# XXGGLL 基本仕様

実装が満たす機能、構成、データ、業務上の強制条件を扱う。機能変更は要件から入り、確定条件と保存方法まで追跡する。

| 文書 | 責務 |
| --- | --- |
| [要件](./requirements.md) | 機能要件、非機能要件、権限、機能gate、受け入れ条件 |
| [アーキテクチャ](./architecture.md) | システム構成、モジュール責務、外部連携、アクセス境界 |
| [データモデル](./data-model.md) | エンティティ、DDL、外部キー、状態、保存禁止項目 |
| [コントロール](./controls.md) | 決済、出金、認可、開示、状態遷移を確定できる条件と監査 |

変更Issueでは、該当する要件ID、コントロール、データ制約、失敗時の状態、テスト条件を一組で記録する。
