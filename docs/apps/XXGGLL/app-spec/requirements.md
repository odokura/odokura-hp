# XXGGLL 要件

## 機能

- ユーザーはメールアドレスとパスワードでアカウントを作成できる。
- クリエイターは公開表示名、無料証票、VIP DMを作成できる。
- ユーザーは証票の取得、購入、保有、継続、返還、再発行を行える。
- 証票の発行・購入・再発行は在庫上限を超えず、同じ対象への同時確定は1件だけ成立する。
- ユーザーは属性を項目ごとに共有・撤回できる。譲渡後に前保有者の共有情報を引き継がない。
- VIP DMは0円で開始する。ユーザーが報酬額を付けたメッセージだけを翌月請求する。
- 有償VIP DMでは、Diditによる本人確認とProfileの性別・生年月日・国籍の全一致を必要とする。
- 管理者は通報、証票、プログラム、VIP DM、返金、送金を管理できる。

## 非機能

- 通貨はJPYだけを使い、金額は整数円で扱う。
- 金銭が発生する機能は手数料パターンDを既定にする。利用者が決済手数料を負担し、返金時の決済手数料はXXGGLLが負担する。
- 監査ログは追記専用とする。
- KYC情報、カード情報、口座情報をアプリケーションDBへ保存しない。
- 外部連絡先、直接取引、性的内容、交際目的、脅迫、勧誘をVIP DMで禁止する。
