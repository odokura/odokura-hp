# XXGGLL 運用・法務

単独管理者が安全にrelease、監視、復旧、精算判断を行うための実施条件を扱う。

| 文書 | 責務 |
| --- | --- |
| [運用](./operations.md) | Railway、Ops、release、監視、incident、backup、定期点検、公開判定 |
| [クリエイター精算](./creator-settlement.md) | クリエイター報酬、精算可能額、返金、出金の契約条件 |

操作手順を短縮しても、固定target、再認証、監査、backup、rollback、機能gateは省略しない。
